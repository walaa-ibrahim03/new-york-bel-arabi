## الجدولة الاختيارية — غير مفعلة

المسار /api/cron/news يتطلب CRON_SECRET عشوائيًا بطول 32 محرفًا على الأقل في Authorization: Bearer، وVERCEL_ENV=production وNYBA_DATABASE_PROFILE=production وNYBA_AUTOMATION_ENABLED=true، ووضع read-write وحارس MATCH. فشل أي شرط يمنع العمل. لا أسرار في URL أو السجلات.

- ملفا docs/vercel-cron-hobby.example.json وdocs/vercel-cron-pro.example.json أمثلة فقط، وليسا إعداد Vercel الفعّال. بعد الموافقة يُدمج مثال واحد في vercel.json ثم يُنشر، دون تغيير DATABASE_URL. التوقيت UTC.
- Hobby: مرة يوميًا؛ لا ندّعي تحديثًا كل نصف ساعة مجانًا عبر Vercel Hobby. Pro: كل 30 دقيقة مقترح. يمكن استخدام مجدول خارجي مصرح به يرسل الترويسة نفسها، لكن لم يُنشأ اشتراك أو ربط أو سر لهذا الغرض.
- قفل PostgreSQL advisory داخل معاملة يمنع تداخل عاملين مجدولين. لا تغيير مخطط. يستخدم الموصل الحالي داخل المعاملة نفسها؛ انتهاء المهلة يُرجع كتابات التشغيل ويحرر القفل، دون بيانات جزئية. المهلة 110 ثوانٍ والوظيفة 120 ثانية.
- حد التشغيل: أول مصدرين معتمدين، خبران لكل مصدر، مع حماية URL الفريدة عند السباق مع الاستيراد اليدوي. المواد المستوردة DRAFT فقط. NYBA_AUTO_PREPARE=true خيار مستقل لا يُفعل افتراضيًا، لإعداد خبرين جديدين كحد أقصى بالعربية في كل تشغيل، باستخدام الأصل المرخّص ونسب المصدر وحماية revision. عند فشل AI تبقى المسودة والأصل للمراجعة اليدوية؛ الأخطاء لا تنشر شيئًا. فشل الجلب أو كتابة قاعدة البيانات يرجع المعاملة ويعيد 503؛ فشل إعداد AI يظهر في failed ووقت المحاولة checkedAt في استجابة المهمة؛ يلزم متابعة نتيجة المجدول وعدم اعتبار HTTP 200 مع failed>0 نجاحًا كاملًا.
- الحارس يفحص الهدف قبل أي جلب. موصلات غير مصرح بها مرفوضة قبل الشبكة. تعطيل العلم أو الرجوع لوضع القراءة فقط يوقف العامل.

## SEO والتغطية

لا حقول جديدة أو Migration: العنوان والوصف حتى 160 محرفًا والكلمات المحورية والرابط الوصفي وCanonical وOG وTwitter وNewsArticle تُشتق من الخبر. لا يُدّعى أن meta keywords عامل ترتيب في Google. الروابط /news/ID القديمة أو ذات عنوان قديم تتحول 308 إلى /news/ID-slug الحالية؛ رقم الخبر يحافظ على الهوية عند تغيير العنوان. لا تُحوّل مسودة إلى صفحة عامة؛ كل استعلام عام يشترط PUBLISHED.

NewsArticle يعرض تاريخ النشر الحقيقي والمصدر ومؤسسة الموقع، دون اختلاق اسم صحفي أو تاريخ تعديل أو صورة. تُضاف روابط أخبار ذات صلة من القسم نفسه. XML Sitemap يشير إلى الروابط الوصفية، وNews Sitemap للأخبار المنشورة في آخر 48 ساعة فقط، بحد 1000، دون الأخبار المستقبلية أو المسودات. robots يشير إلى الخريطتين ويحجب الإدارة وAPI؛ المعاينات على Vercel وبيئة الاختبار تبقى noindex/disallow. يلزم NEXT_PUBLIC_SITE_URL صحيحًا بـHTTPS للنطاق الرسمي. قد يحتاج /sitemap.xml إلى تقسيم عند الاقتراب من 50 ألف URL؛ حجم الموقع الحالي أقل بكثير.

الأقسام القديمة محفوظة، وأضيفت أخبار أمريكا وأخبار العالم وترند. يتصدر خبر من نيويورك الرئيسية إن وجد. قسم «الأكثر تداولًا الآن» يوضح أنه ترتيب محلي: تقارب عناوين أخبار منشورة خلال 24 ساعة، أو اختيار المحرر لقسم ترند، مع وقت آخر خبر منشور. لا إحصاءات عالمية أو زيارات مختلقة، ولا اشتراط تكرار الموضوع لصلاحية نشر خبر واحد. عند عدم كفاية الإشارات يعرض ذلك بوضوح.

للصور الموجودة أبعاد ثابتة وAlt ووضع فك ترميز غير متزامن، وتحميل بطاقات الأخبار كسول، لتقليل CLS وحجم العمل على الهاتف. لا تنزيل صور الناشرين أو تفعيل Blob. المعالجة الآمنة إلى WebP القائمة تبقى جاهزة عند تفعيل التخزين لاحقًا. لم يُضف wildcard لمضيفي الصور، ولم نَعِد بدرجة Core Web Vitals دون بيانات فعلية؛ قياس LCP/INP/CLS الميداني يكون بعد النشر عبر Search Console/CrUX. تحسين نسبة الأبعاد لا يحل بطء مضيف خارجي؛ تُفضل صور مرخصة مضغوطة على تخزين معتمد لاحقًا.

3. نشر مرحلي من إعدادات Production الحالية دون تحويل النطاق، وفحص MATCH وnoindex للمعاينة، وCSS والمصادقة والنموذج والروابط الجديدة/XMl بقراءات آمنة. ثم تحويل النطاق. الرجوع لإصدار c975a267 ممكن دون استعادة بيانات أو حذف أعمدة؛ تعطيل العامل قبل الرجوع إذا فُعّل.
4. Search Console: إثبات ملكية النطاق عبر DNS بعد إذن منفصل، أو URL-prefix عبر GOOGLE_SITE_VERIFICATION المجهز في metadata. إرسال sitemap.xml وnews-sitemap.xml، وفحص URL منشور وRich Results Test. لم تُنشأ ملكية أو يُعدّل DNS أو تُرسل طلبات فهرسة هنا.
5. استكمال جهة التحرير ووسيلة تواصل عامة حقيقية قبل طلب أهلية Google News؛ صفحة /about أضيفت للسياسة التحريرية دون اختلاق اسم مدير أو بريد تواصل. Google يختار الأخبار المؤهلة تلقائيًا؛ لا ضمان قبول أو ترتيب أول. لا يكفي إنشاء Sitemap وحده.

## التكلفة

- التكلفة المدفوعة خلال المهمة: صفر؛ لا API مدفوع أو موارد سحابية جديدة شُغلت. لا رسوم إضافية لحقول SEO أو الخرائط أو دليل المصادر، ولا اشتراك Blob.
- Vercel Hobby: 0 دولار ضمن الحدود وللاستخدام الشخصي غير التجاري، وCron يومي فقط. Pro يبدأ 20 دولارًا شهريًا مع مقعد واحد ورصيد استخدام 20 دولارًا؛ الاستهلاك الزائد والضرائب منفصلان. القرار مهم إذا أصبح الموقع تجاريًا.
- النموذج الحالي المحفوظ هو gpt-5.1؛ أضيف OPENAI_NEWS_MODEL لتغييره دون إعادة كتابة النظام. وثيقته تعرض Deprecated؛ قبل تفعيل AI يلزم اختيار نموذج Responses/Structured Outputs يدعم reasoning.effort=none ومتاح في الحساب، أو تأكيد استمرار النموذج الحالي. لم نختبر توافر الحساب باستدعاء مدفوع ولم نبدل النموذج افتراضيًا. تعرفة gpt-5.1 المنشورة: 1.25 دولار/مليون input و10 دولارات/مليون output. مثال حسابي لا فاتورة: 2000 input و900 output ≈ 0.0115 دولار للمسودة، أو 1.15 دولار لكل 100 مسودة، دون إعادة المحاولات. التكلفة الفعلية حسب tokens والنموذج المختار؛ مع reasoning=none وسقف 900 output ولا إعادة محاولة تلقائية.
- Reuters/AP وغيرها: بعقد وعرض سعر، لا سعر مجاني مخترع ولا ترخيص مفعّل. GSC وGoogle News لا يتطلبان رسم اشتراك لفهرسة الموقع.
