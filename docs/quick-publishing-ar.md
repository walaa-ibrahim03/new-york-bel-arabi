# النشر السريع للأخبار

حلّ مكان الاكتشاف وقسم الاستيراد المكرر داخل لوحة الإدارة الحالية؛ لا شاشة إدارة جديدة أو Migration. تبقى إضافة الخبر اليدوية والمحرر ودليل المصادر والإجراءات القديمة على الخادم للتوافق.

## التشغيل

1. المصدر والقسم ثم «جلب أحدث 5 أخبار». المصدر الافتراضي NASA، لأن أذوناته الحالية تغطي RSS وإعداد العربية. CNN وBBC والجزيرة وReuters وAP والعربية وغيرها تبقى للمتابعة اليدوية مع السبب ورابط إعداد الوقائع؛ لا عقد/مفتاح API جديد أو تجاوز حماية.
2. تُرتب نتائج التغذية الصالحة بتاريخها وتُرشح للقسم وتُستبعد الأخبار المحفوظة والروابط المكررة. نيويورك تتطلب إشارة مكانية، والصحة/التعليم/الهجرة/الاقتصاد كلمات موضوعية صريحة؛ أمريكا تشمل مصدرًا أمريكيًا أوليًا مثل NASA. هذه قواعد ترشيح وليست ادعاء فهم شامل للمادة. لا تُملأ الخانات بنتائج عشوائية: قد يقل العدد عن خمسة عند قلة النتائج أو نقص التاريخ/المعلومات أو وجود أخبار محفوظة. الروابط تبقى على نطاق مصدر RSS المعتمد؛ لا سحب مقال أو صورة.
3. الترند الآلي غير متاح لغياب مؤشر اهتمام خارجي موثق. لا يُستبدل بتاريخ أحدث أو تكرار محلي ويسمى ترندًا. بقية الأقسام تعمل.
4. البحث لا يحفظ أخبارًا ولا يستدعي AI. نتائج غير مختارة في ذاكرة المتصفح وتختفي عند تغيير البحث. الاختيارات موقعة بـHMAC منفصل السياق باستخدام AUTH_SECRET الموجود، وتُرفض عند العبث أو بعد 20 دقيقة؛ لا يظهر السر للمتصفح. لا إعداد جديد.
5. «تجهيز الأخبار المختارة» يعالج حتى خمسة بالتتابع، طلب خادم/AI مستقل لكل واحد لتفادي مهلة طلب طويل. يتحقق مجددًا من المدير وMATCH وأذونات المصدر. يُنشئ مسودة أصلية تحت sourceUrl الفريد **قبل** AI، لمنع السباق وإعادة التكلفة عند النقر المكرر. يحفظ originalTitle/originalSummary/originalContent ثم يطلب صياغة عربية مستهدفة 40–80 كلمة بالنموذج الموجود، ويتحقق من الأرقام والحدود والعربية. لا يضيف صورة ناشر.
6. إذا فشل AI أو التحقق، تبقى المادة الأصلية مسودة غير منشورة مع رابط للمحرر. لا إعادة مدفوعة تلقائية؛ إذا تعطلت خدمة AI تتوقف بقية الدفعة. نتائج غير معالجة لا تُحفظ. يمكن إعادة المحاولة الصريحة من المحرر بعد معالجة السبب. المسودة القصيرة جدًا لا تُمدد بالاختلاق للوصول إلى عدد كلمات؛ المدير يراجع النص دائمًا. النتائج الأطول من 80 كلمة تُرفض للمراجعة بدل قص الحقائق.
7. المعاينة قابلة لتعديل العنوان والملخص، مع حفظ مسودة أو نشر بعد تأكيد واحد. يعاد استخدام updateArticle ومسار الاعتماد الموجود: مراجعة/اعتماد/نشر في كتابة مشروطة برقم revision، مع حماية المدير وMATCH. أي تحرير متزامن يمنع الكتابة القديمة؛ لا استبدال للأصل. SEO والـslug وCanonical والخرائط تُشتق كما في الإصدار السابق.

## الصور والسوشيال

- لا تُجلب صور المصدر تلقائيًا. لم يُثبت إذن صور وتعديل/وسم لكل مادة، فلا افتراض بوجوده.
- لكل معاينة غلاف تحريري أصلي بأشكال وألوان وهوية NY bel Arabi، مع توضيح أنه تصميم وليس صورة للحدث. بعد نشر الخبر يمكن توليد PNG ‏1080×1080 في المتصفح وتنزيله؛ لا Blob أو تخزين دائم أو API صور أو رسوم جديدة. النص يعمل مستقلًا عن الصور. الصور القديمة الموجودة لا تتغير، ولا تُرفع الأغلفة إلى الموقع تلقائيًا.
- نصا فيسبوك وإنستغرام والهاشتاغات مشتقة محليًا من الخبر المحفوظ، دون AI إضافي أو ادعاءات جديدة. تظهر في المعاينة بعد نشرها، وكذلك داخل محرر الخبر المنشور. قابلة للتعديل والنسخ، وليست إرسالًا إلى الحسابات.
- الربط المستقبلي يحتاج تطبيق Meta رسميًا، وحسابات/صفحة مؤهلة، ومراجعة الأذونات المطلوبة وقت التنفيذ، وتخزين رموز الوصول بأمان وموافقة منفصلة قبل أي نشر. لا ربط أو أذونات أو أسرار اجتماعية أضيفت الآن.

## التكلفة والفحوص

لا اشتراك استضافة أو تخزين جديد: 0 دولار إضافية ثابتة ضمن الخطة القائمة وحدودها. OpenAI حسب الاستهلاك الحالي؛ بتعرفة gpt-5.1 المنشورة 1.25 دولار/مليون إدخال و10 دولارات/مليون إخراج، مثال 2000 إدخال و900 إخراج = 0.0115 دولار/خبر، 0.0575 لكل خمسة، و1.15 لكل 100 خبر. ليست فاتورة أو سقفًا عامًا؛ حجم النص/الاستهلاك يغير التكلفة. لا تغيير للنموذج أو المفاتيح، ولا طلبات AI حقيقية أثناء الاختبارات. السوشيال والغلاف لا يضيفان رسوم API.

اختبارات معزولة تشمل الترشيح والترتيب وندرة النتائج ومنع التكرار والتوقيع والانتهاء، عدم حفظ البحث، الاختيار الجزئي، إعادة النقر والسباق، فشل AI وتوقف الدفعة، حماية المدير/الوضع/الحارس، الأصل والاعتماد والنشر والتعارض، مشتقات السوشيال وإنشاء الرسم دون مصدر أو تخزين. فُحص PNG عربي حقيقي في متصفح ببيانات خيالية وخادم loopback مؤقت؛ لا اتصال بقواعد أو أخبار حقيقية. يليها TypeScript وESLint وبناء الإنتاج وفحص CSS، ثم Commit وأرشيف دون env ونشر مرحلي للقراءة فقط وMATCH قبل النسخة الرسمية للكتابة. تبقى الجدولة وAI الخلفي وBlob معطلة.
