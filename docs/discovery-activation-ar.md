# فصل التفعيل التقني عن سياسة الاكتشاف

`discovery.automatic` يعني جاهزية الموصل التقنية، و`headlineAccess` يحدد سياسة الوصول بشكل مستقل (allowed/restricted). `discovery.reference` توثيق اختياري لا يدخل في قرار التشغيل؛ غيابه أو فراغه لا يعطل مصدرًا مسموحًا. لا يتطلب اكتشاف العناوين automaticImport أو translation. تبقى بوابات النص الكامل والمقتطفات منفصلة، وحصر روابط المصدر وحارس الاتصال وصلاحيات المدير بلا تغيير. المصادر القديمة المسموحة تحتفظ بإمكانية اكتشافها.

سجلت نقاط RSS الأربع الموجودة بالفعل في نطاق الطلب (ABC7NY وNBC New York وNew York Post وSILive) وربطتها بالدليل وواجهة إعداد خبر. يعرض المكون نفسه أحدث خمس نتائج وتواريخها وروابطها ومربعات الاختيار ومسودات المراجعة عبر Server Actions الموجودة عندما canDiscoverHeadlines=true. لا طلب عند رسم الواجهة، ولا إعادة بناء RSS أو شاشة جديدة. نطاق الواجهة المحلية أربعة مصادر فقط.

السياسة الفعلية للأربعة restricted كما في مراجعة شروط الوصول السابقة؛ نجاح RSS تقنيًا لا يقلب السياسة إلى allowed. لا زر جلب وهمي، ولا تفعيل عبر مدخل من العميل أو متغير يتجاوز القيود. لم يعاد فحص RSS الحي أو استدعاء AI؛ الاختبارات تستخدم أخبارًا خيالية وRSS/Prisma/AI معزولة، وتثبت خمس نتائج لمصدر ذي وصول allowed حتى دون reference ودون إذن ترجمة، ومنع restricted قبل الشبكة.

هذه حزمة محلية مختبرة وليست إثباتًا لظهور عناوين حقيقية مسموحة من الأربعة. النشر مؤجل التزامًا بشرط عدم نشر واجهة قبل إثبات التشغيل المسموح. لا تعديل أخبار أو قاعدة بيانات أو أسرار أو Migration.
