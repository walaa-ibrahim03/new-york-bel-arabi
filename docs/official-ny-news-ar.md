## نطاق التشغيل

المسار الحالي نفسه: القسم (افتراضي «كل أخبار نيويورك») ← جلب أحدث الأخبار ← تحديد النتائج ← تجهيز المسودات ← مراجعة وتأكيد «نشر الآن». اختيار المصدر الواحد انتقل إلى «مصادر أخرى (اختياري)» للحفاظ على الموصلات السابقة. لا جدولة جديدة أو نشر تلقائي، ولا خدمات أو إعدادات إضافية.

المجمّع يشمل المدينة والولاية، وأخبار الهجرة المرتبطة بنيويورك أو سياسات التقديم العامة. ليس ادعاءً بتغطية جميع الجهات، ولا يضيف خبرًا قديمًا أو قضية محلية في ولاية أخرى لإكمال العدد. حتى 5 نتائج صالحة بعد استبعاد المحفوظ والمكرر، مرتبة حسب تاريخ النشر الأصلي. التصنيف من العنوان/وسوم RSS والجهة، متوافق مع التصنيفات الحالية، بلا Migration.

## حدود وأمان

- ثلاثة endpoints ثابتة فقط؛ Promise.allSettled يعزل الفشل، مهلة 8 ثوان لكل مصدر، ولا تحويلات HTTP أو إعادة محاولات تلقائية.
- حد 512KB للاستجابة و200 عنصر؛ رفض DTD/ENTITY. ذاكرة مؤقتة 60 ثانية ودمج الطلبات المتزامنة لنفس الموجز داخل العملية؛ لا حفظ أخبار البحث في قاعدة البيانات.
- صلاحيات المدير وMATCH تسبقان طلبات البحث. القراءة فقط تسمح بالاكتشاف دون أي حفظ/AI؛ تجهيز المسودات والاستيراد الكامل والترجمة والحذف والاعتماد والنشر تبقى ممنوعة فيها على الخادم وطبقة Prisma.
- حداثة 14 يومًا للأخبار الرسمية، و6 ساعات للتنبيهات؛ استبعاد المستقبل والتواريخ المفقودة. لا يُفهم توقيت النشر بوصفه تاريخ وقوع الحدث. لا إضافة لخبر قديم عندما تقل النتائج عن 5.
- USCIS: مرشح نيويورك، أو إعلانات سياسة/أهلية/رسوم/نماذج/فترات تسجيل عامة؛ لا تُعد كل قضية وطنية خبرًا محليًا.
- روابط Notify NYC محصورة في tenant الرسمي `/feeds/453003085617722/cap/`، وليس أي عميل آخر على Everbridge. بقية الروابط يجب أن تطابق مضيف الجهة المسجلة، دون بيانات اعتماد أو نطاقات عشوائية.
- تكرار URL الموحّد والعنوان المُطبّع مستبعد عبر الجهات والأخبار المحفوظة؛ كل النتائج موقعة ومحدودة الصلاحية. المصدر والرابط يثبتان من الرمز، لا من مدخلات العميل.
- الاستدعاء المدفوع عند تجهيز المختار فقط، بنفس النموذج القائم، دون إعادة تلقائية. مقتطف وقائعي حتى 1200 حرف عند السماح به؛ ملخص 40–80 كلمة أو أقصر دون اختلاق. لا حفظ لغير المختار أو نشر تلقائي.

## التحقق والنشر

اختبارات RSS/AI/Prisma معزولة، تشمل التجميع والترتيب والتكرار والحداثة والتصنيف، فشل مصدر/كل المصادر، صلة USCIS، حدود النقل ودمج الطلبات، حدود tenant، قراءة فقط، تجهيز المختار والنشر المؤكد. فحص عام للموجزات دون DB أو AI. ثم TypeScript وESLint وبناء الإنتاج/CSS، Commit محلي، حزمة نظيفة بلا ملفات بيئة، فحص إصدار محمي قبل ربط النطاق. لا Migration ولا تغيير DATABASE_URL أو OAuth أو المفاتيح أو الأخبار الحالية. الجدولة والصور تبقيان كما كانتا.
