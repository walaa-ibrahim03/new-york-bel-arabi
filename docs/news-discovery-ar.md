# فصل اكتشاف الأخبار عن استيراد النصوص

سبب الرسالة السابقة: لوحة الإدارة اختارت Gothamist افتراضيًا، مع أن إذن استيرادها وترجمتها معطّل. الرسالة كانت تخص الاستيراد النصي؛ لم تكن دليلًا على توقف إضافة الأخبار أو النشر اليدوي.

## المسار الجديد

1. قسم «اكتشاف الأخبار»: قائمة جميع المصادر الموجودة، منها CNN وBBC والجزيرة وReuters وAP والعربية والمصادر الأولية. روابط المصادر تُفتح مباشرة في نافذة مستقلة، بلا إطار أو نسخ لعناوينها إلى الموقع. تبقى شروط الوصول والحجب/الاشتراك واجبة الاحترام؛ لا تجاوز لها ولا ادعاء ترخيص عام للاستخدام المهني.
2. «إعداد خبر من الوقائع» يفتح المحرر باسم المصدر، وفي وضع الوقائع المستقلة افتراضيًا. أدخلي رابط الخبر المحدد ووقائع قصيرة تحققت منها وكتبتها بأسلوبك (لا المقال)، ثم أكديها واطلبي معاينة عربية 40–80 كلمة. الأصل والمصدر والرابط تُحفظ داخليًا عند الحفظ الصريح فقط. المعاينة قابلة للتعديل؛ لا حفظ أو نشر تلقائي. الحقوق والترجمة الكاملة تظل محمية ببواباتها السابقة.
3. NASA وحدها لها إذن اكتشاف آلي موثق: زر يعرض حتى عشرة عناوين وروابط دون نصوص أو صور ودون أي كتابة لقاعدة البيانات أو استدعاء AI. اختيار عنوان يملأ عنوانه ورابطه واسم المصدر في النموذج، ولا يجلب المقال. الاستيراد النصي مستقل تحت قسم RSS، وأذوناته مستقلة؛ السماح بعناوين مصدر لا يجيز تخزين نصوصه أو ترجمتها.
4. قائمة استيراد النصوص تختار مصدرًا معتمدًا (NASA حاليًا)، وتوضح تعطيل المصادر الأخرى بدل عرض منع عام كمسار افتراضي. الاستيراد لا ينشر. الجدولة تبقى معطلة.

## سياسة الوصول — مراجعة 2026-10-17

- NASA: RSS الرسمي https://www.nasa.gov/rss-feeds/ وشروط الاستخدام الإعلامي https://www.nasa.gov/nasa-brand-center/images-and-media/ يدعمان الاستخدام المعلوماتي مع النسبة؛ لا صور أو مواد طرف ثالث.
- الجزيرة: https://terms.aljazeera.net/index-ar.html، القسم 6، يحظر الجمع الآلي والتنقيب وإعادة الاستخدام غير المصرح به؛ القسم 7 يسمح بالروابط المباشرة إلى صفحات كاملة دون تضمينها. الرابط الخارجي للمتابعة فقط؛ موصل آلي غير مفعّل.
- AP: https://www.ap.org/terms-and-conditions/، القسم 2.2، يقيّد الجمع والمراقبة الآلية، فلا موصل عناوين أو نصوص دون ترخيص. رابط الصفحة الرئيسية ليس API أو إذن إعادة استخدام.
- BBC: https://www.bbc.com/usingthebbc/terms/ يحيل إلى شروط استخدام المحتوى والأعمال؛ لا ترخيص آلي مثبت لموقعنا. CNN: https://arabic.cnn.com/terms أعاد 451 لأداة المراجعة؛ تعذر تأكيد نطاق الإذن، ولذلك لم يُفعّل الجمع الآلي. عدم إتاحة صفحة الشروط ليس إذنًا.
- Reuters والعربية وGothamist وTHE CITY وamNewYork: المتابعة بروابط رسمية؛ لا موصل جمع آلي جديد ولا تغيير للأذونات المقيدة السابقة. THE CITY لها قيود إعادة نشر/نسبة وعدم اشتقاق؛ لا يجيز هذا التحديث ترجمة محتواها أو إعادة نشره وفق ترخيصها العام.
- NYC وUSCIS: روابط أولية للمتابعة والتحقق؛ لا موصل آلي جديد أو افتراض شمول كل مادة بترخيص واحد.

هذه قائمة وصول وتشغيل، وليست ترخيصًا لنسخ مقالات محمية أو ضمانًا قانونيًا لكل استخدام. إذا لم يكن للمحرر حق الوصول/استخدام الوقائع في غرضه، يستخدم مصدرًا أوليًا أو مرخصًا آخر. لا يُرسل نص المقال المحمي إلى الذكاء الاصطناعي تحت مسمى الوقائع.

## التحقق والأمان

طلبات الاكتشاف تتطلب المدير والحارس ووضع الكتابة قبل الشبكة. المصدر مسجل مسبقًا، ولا URL تعسفي أو تجاوز تحويلات؛ تبقى قيود RSS القائمة. الروابط تُنقّى وتطابق نطاق المصدر وتُزال المكررات؛ لا HTML يُعرض مباشرة. تشغيل الاكتشاف لا يقرأ أو يكتب أخبار القاعدة. اختبارات بلا شبكة أو موارد إنتاج تغطي البوابات وفصل إذن العناوين عن الاستيراد، وتجريد النصوص، وتوجيه المحرر والمحافظة على النشر وSEO.
